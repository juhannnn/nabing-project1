### Online Resume - Johan Cedrick C. Nabing

Welcome to my online resume project. This website was created using HTML only as part of my web development project. It presents a brief summary about me, educational background, work experience, skills, awards, certifications, hobbies, and contact informations.

### About Me

I am a third-year Information Technology student at **Batangas State University - Alangilan Campus**, majoring in **Business Analytics**. I am highly interested in data analysis, data interpretation, and using technology to transform data into meaningful insights.

I am continuously developing my technical, analytical, and problem-solving skills through academic projects and hands-on activities.

### Website Features

The website consists of three main pages:

### 1. Home 

The Home page contains:

- Profile photo
- Personal information
- Summary
- Educational background
- Work experience and IT-related projects
- Technical and analytical skills
- Awards
- Certifications
- Links to the Contact and Hobbies pages

### 2. Contact

The Contact page contains:

- Name
- Gmail
- Phone number
- Location
- Facebook
- Instagram
- GitHub

### 3. Hobbies

The Hobbies page contains:

- Personal activities and interests
- IT-related activities
- Data analysis and interpretation interests
- Web design interests
- Programming and learning activities

### Technologies Used

This project was created using:

- **HTML5**
- HTML semantic elements
- Hyperlinks
- Lists
- Images
- Multi-page navigation

No CSS or JavaScript was used in this project.
